# marsianskiy

Windows 10/11 x64 VPN-клиент с раздельной маршрутизацией сервисов. Движок: **mihomo 1.19.33**, уже включён в пакет.

## Запуск

1. Распакуйте `marsianskiy-win-x64.7z` для portable-запуска либо запустите `marsianskiy-setup.exe` для установки в Program Files и создания ярлыков.
2. Запустите `marsianskiy.exe` и подтвердите права администратора: они нужны mihomo для TUN и защиты DNS Windows.
3. Импортируйте собственную подписку через скрытое поле URL, локальный файл или буфер обмена. Ничего не нужно отправлять в чат.
4. Нажмите «Автовыбор · HTTPS» либо выберите сервер вручную в списке/на карточке.
5. Включите нужные сервисы и нажмите «Подключить VPN».

При первом запуске отображается анимированный приветственный экран с вращающимся точечным 3D-глобусом, спутниками и реакцией на курсор. Кнопка «Настройки» открывает автозапуск через Планировщик заданий Windows, автоподключение последней конфигурации, сворачивание в системный трей, параметры Gemini, редактор маршрутов, локальную папку данных, повторный показ приветствия и создание ярлыка на рабочем столе. Стрелка на карточке открывает сайт сервиса. Переходы, карточки, кнопки и переключатели имеют плавные анимации.

Поддерживаются обычный список URI и base64/base64url-список. Реализованы **VLESS + REALITY через TCP** и **Hysteria2**. Другие протоколы и транспорты не выдаются за поддерживаемые: импортер пропускает их с текстовой ошибкой.

Боковая навигация с иконками и активной подсветкой разделяет главную с глобусом и быстрыми ярлыками, карточки сервисов и страницу серверов. Все 22 фирменных SVG-логотипа и иконки действий встроены локально через SharpVectors. Fortnite маршрутизируется по доменам Epic/EAC и процессам игры/лаунчера, без перенаправления всего AWS/CloudFront; для игрового UDP нужен сервер с поддержкой UDP. В списке сервисов работает поиск по названию и описанию, а в нижней строке отображается время активной VPN-сессии. Глобус использует кэшированные кисти и останавливает отрисовку при скрытии.

«Автовыбор» запускает настоящий HTTPS-запрос через каждый импортированный узел (не более четырёх параллельных проверок) и выбирает доступный узел с минимальной задержкой. Один импортированный сервер не создаёт иллюзию выбора. Страны берутся только из названий серверов; подпись можно исправить вручную.

## Маршруты и безопасность

- Включённые домены/IP идут через узел соответствующей карточки, остальное — `DIRECT`; процесс браузера целиком не проксируется.
- DNS использует Yandex `77.88.8.8` с резервом `77.88.8.1`: выбранные домены — через тот же VPN-узел, остальные — напрямую. Windows DNS на время VPN направляется в mihomo на `127.0.0.1`; исходные адреса сохраняются и восстанавливаются после остановки. Для выбранных сервисов нет fallback на `DIRECT`; при сбое отображается состояние и доступно переподключение.
- Предусмотрены блокировка второго экземпляра, предупреждение о конфликтных VPN-адаптерах, аварийное восстановление mihomo и автопереключение на резервный узел с ограничением частоты.
- Кнопка «Проверить маршрут» сравнивает 2ip и прямой IP. Отчёт поддержки сохраняется без подписки, UUID, адресов серверов, REALITY-ключей и публичных IP.
- Подписка обновляется по расписанию с сохранением ручных стран/маршрутов. Профили «Игры», «Стриминг» и «Работа» переключают группы карточек. Обновление mihomo проверяет официальный SHA-256 и делает откат при ошибке.
- В настройках доступны автопереключение и уменьшение движения.
- `services.json` можно открыть из приложения. При загрузке проверяются доменные и CIDR-пересечения и запрещены чрезмерно широкие корни вроде `google.com` и `cloudflare.com`.
- Gemini не включает Google Sign-In, пока пользователь не активирует отдельную настройку.
- Состояние с UUID, паролями и ключами шифруется Windows DPAPI текущего пользователя. Временные YAML-файлы имеют ACL текущего пользователя и удаляются после остановки. URL и секреты маскируются в сообщениях.
- Аналитики и собственного удалённого backend у приложения нет. Сетевая активность ограничена загрузкой указанной пользователем подписки, VPN-узлами, DNS и HTTPS-проверкой `www.gstatic.com/generate_204`.

Локальные данные: `%LOCALAPPDATA%\marsianskiy`. Изменённый файл маршрутов: `%LOCALAPPDATA%\marsianskiy\services.json`.

## Сборка из исходников

Требуется .NET SDK 8 и Windows x64:

```powershell
dotnet publish src/Marsianskiy/Marsianskiy.csproj -c Release -r win-x64 --self-contained true -o artifacts/marsianskiy-win-x64
```

Проверка парсера, каталога и реальной валидации конфигурации движком:

```powershell
.\marsianskiy.exe "--verify=$PWD\verification.txt"
```

Команда использует только синтетические локальные URI и не подключает TUN/VPN.
